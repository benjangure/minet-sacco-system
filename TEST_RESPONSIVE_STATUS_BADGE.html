Mobile Testing Instructions

🔍 To test mobile view:

  1. Press F12 to open Developer Tools
  2. Click the device toggle icon (or press Ctrl+Shift+M)
  3. Select a mobile device (e.g., iPhone 12, Pixel 5)
  4. Observe the status badges switch to shorter labels
  5. Try different screen widths to see the breakpoint at 640px

Expected behavior:

  • < 640px: Shows shorter labels like "Officer Review", "Committee"
  • ≥ 640px: Shows full labels like "PENDING LOAN OFFICER REVIEW"
