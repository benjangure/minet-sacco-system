HOW TO USE:
-----------

1. ADD NOTIFICATION SETTINGS TO YOUR APP:
   Import and use the NotificationSettings component in user settings page
   
   Example:
   import NotificationSettings from '@/components/NotificationSettings';
   
   <NotificationSettings />

2. ADD NOTIFICATION PROMPT (Optional):
   Show prompt after user login to request permission
   
   Example in dashboard:
   import NotificationPrompt from '@/components/NotificationPrompt';
   
   <NotificationPrompt />

3. MANUAL USAGE IN COMPONENTS:
   import { useDesktopNotifications } from '@/hooks/useDesktopNotifications';
   
   const { showLoanNotification, showDepositNotification } = useDesktopNotifications();
   
   // Show notification
   showLoanNotification('Your loan has been approved!', loanId);


NOTIFICATION TYPES:
-------------------
- showLoanNotification(message, loanId)
- showDepositNotification(message, depositId)
- showGuarantorNotification(message, requestId)
- showApprovalNotification(message, itemId)
- showSystemNotification(message)
- showNotification(title, body, options)


AUTOMATIC NOTIFICATIONS:
------------------------
Desktop notifications are automatically triggered when WebSocket messages arrive for:
- LOAN_APPROVED
- LOAN_REJECTED
- LOAN_DISBURSED
- DEPOSIT_STATUS_CHANGED
- GUARANTOR_REQUEST
- TRANSACTION updates
- SYSTEM notifications


TESTING:
--------
1. Login to the application
2. Click "Enable Notifications" when prompted (or in settings)
3. Grant browser permission
4. Perform actions like loan approval, deposits, etc.
5. Desktop notifications will appear automatically


BROWSER SUPPORT:
----------------
- Chrome/Edge: Full support
- Firefox: Full support
- Safari: Full support (macOS/iOS)
- Opera: Full support

Not supported in IE11 or older browsers.


TROUBLESHOOTING:
----------------
1. No permission prompt appears:
   - Check if browser supports notifications
   - Look for blocked notification icon in address bar
   
2. Permission denied:
   - User must manually enable in browser settings
   - Chrome: Settings > Privacy > Site Settings > Notifications
   
3. Notifications not showing:
   - Check browser notification settings
   - Ensure "Do Not Disturb" is off (macOS/Windows)
   - Check system notification settings
