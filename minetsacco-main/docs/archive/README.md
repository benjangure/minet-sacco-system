# Archived Documentation

This folder contains diagnostic, reference, and development documentation that was archived during pre-deployment cleanup.

## Purpose
These files were created during development and debugging but are not needed for production deployment. They are kept here for historical reference and troubleshooting if needed.

## Contents
- **Bug Analysis & Fixes**: Root cause analyses, diagnostic reports, and fix summaries
- **Feature Implementation**: Implementation plans, status reports, and technical analyses
- **Password Change Feature**: Complete documentation of password change feature development
- **Loan Workflow**: Loan number generation, workflow audits, and repayment display fixes
- **Guarantor Features**: Guarantor reassignment and rejection handling documentation
- **Deployment Guides**: Earlier deployment documentation (superseded by production guides)
- **Session Summaries**: Work summaries and action items from development sessions

## Production Documentation
For production deployment, refer to these documents in the root directory:
- `PRODUCTION_DEPLOYMENT_GUIDE.md` - Complete deployment instructions
- `DEPLOYMENT_QUICK_REFERENCE.md` - Quick lookup for commands
- `DEPLOYMENT_CHECKLIST.md` - Execution checklist
- `README.md` - Project overview
- `USAGE_GUIDE.md` - System usage guide

## Note
If you need to reference any archived documentation during troubleshooting, all files are preserved here with their original names.
