================================================================================
4. BUSINESS LOGIC
================================================================================

✅ NOK Guarantor Rules:
   1. Every primary guarantor MUST have a NOK
   2. NOK guarantee amount MUST equal primary amount
   3. NOK cannot be same person as primary
   4. NOK cannot be another primary guarantor on same loan
   5. NOK must be ACTIVE member with sufficient savings
   6. Both primary AND NOK approve simultaneously
   7. Both primary AND NOK savings frozen immediately

✅ Member Exit Rules:
   1. Only TREASURER/ADMIN can mark member as exited
   2. Exit reason and date are required
   3. System finds all active guarantees where member is primary
   4. For each guarantee:
      - If NOK exists: NOK promoted to primary automatically
      - If no NOK: Borrower notified to find replacement
   5. Member status changed to EXITED
   6. Member's frozen savings released
   7. Audit trail recorded

✅ Notifications Sent:
   - Exited member
   - Borrowers where member was guarantor
   - NOK guarantors who are promoted to primary
